# C 奶油胶带剪贴 / cream-tape

代表图：`references/images/style-tape.jpg`（带锁屏界面的截图）。只学习紙底、边缘、胶带、涂鸦、字块与留白。路径相对技能根目录。

## 不变量

- 暖奶油轻纤维纸，上方大面积安静空间。
- 一个中下照片剪贴或紧凑多宠组，规模克制。
- 较宽白留边、薄灰撕纸外层、短浅接触阴影。
- 左侧米色点纹胶带，右下斜格纹胶带，均压纸边而不遮脸。
- 稀疏铅笔笑脸水滴、小椭圆思考气泡、少量逐词剪下的文字纸块。

原参考 5.png、6.png、7.png 是同风格换主体，不是三个独立风格。

## 构图与输入

头胸贴纸大致 x=.24—.78、y=.45—.75，按实际姿态调整。顶部约 .30—.40 安静，可有极淡涂鸦，不画巨大假时钟填空。字块成小组，不能散落满屏。

只有头像就做头像剪贴，保持自然头身比例。多宠可为共同合照剪贴或相邻小组；不补参考猫的身体、爪子或细长手臂。允许原照片的直线下沿裁切。

## 文字与材质

气泡可选 `想你啦`、`love you` 等短句；用户要求“重度依赖”等按原文。剪报可用 `you make my day` 等简短完整表达。无文字时删气泡词与字块文字，保留少量空纸片、胶带、水滴，不留乱码。

奶油/燕麦/米灰轻微变化。不要自动加蕾丝、星星簇、唱片或大彩绘花线稿。

## 提示与验收

真实摄影姿态 → 暖纸大留白 → 中下克制主角 → 白灰撕纸轮廓 → 两胶带 → 铅笔水滴 → 小气泡与字块。

# A 便签撕纸 / mono-tear-collage

代表图：`references/images/style-heart.jpg`。路径相对技能根目录。

## 背景与主体

- **背景**：暖米色/浅驼色纯色纸底，无任何暗纹，干净低饱和。
- **主体**：居中略偏下的摄影宠物撕纸贴纸。撕纸边缘为不规则白色毛边，像从纸洞里探出来，不是整齐贴纸边。几乎无明显阴影，平贴感。
- **主体比例**：宽约画面的45%—55%，随照片形态自适应。顶部留30%—35%安静留白，底部留10%安全边距。

## 装饰元素与相对位置

所有装饰围绕主体分布，紧贴主体边缘，随主体形态自适应，不写死坐标：

| 元素 | 方位 | 大小（相对主体宽度） | 样式（固定） |
|---|---|---|---|
| 波点胶带 | 左下方，斜贴在主体左下边缘 | 15%—18% | 黑白波点，撕纸效果 |
| 格纹胶带 | 右上方，斜贴在主体右上边缘 | 15%—18% | 浅米色格纹 |
| 千鸟格胶带 | 右下方，斜贴在主体右下边缘 | 15%—18% | 黑白千鸟格 |
| 线圈涂鸦 | 左侧（主体左上方） | 约主体宽度的10% | 黑色乱涂圆圈线条 |
| 空心轮廓星 | 头顶上方 + 左下方各1个 | 8%—10% | 黑色细线空心五角星 |
| 实心黑底星 | 右下方 | 12%—15% | 黑底，内部多个小白星 |
| 小星号 ✳️ | 左下方，空心星旁边 | 约3% | 很小的星形符号 |
| 椭圆气泡框 | 右上角（主体右上方） | 约主体宽度的30% | 黑色细线椭圆框，内部手写英文，底部小空心爱心 |
| 格纹便签纸 | 右下角（主体右下方） | 约主体宽度的1/4—1/5 | 边缘不规则毛糙，底色低饱和呼应宠物衣服主色 |

### 分布逻辑

- **左侧**：线圈涂鸦（上）+ 空心星 + 小星号（下）
- **右侧**：气泡框（上）+ 千鸟格胶带 + 实心星 + 便签纸（下）
- **顶部**：格纹胶带斜贴 + 空心星
- **底部**：波点胶带斜贴

装饰紧凑围绕主体，不漂浮在背景上空，不分散。

## 配色与文字

整体为纯黑白灰 + 暖米色纸底，无彩色点缀。宠物与衣服保留原色。便签纸底色可呼应宠物衣服主色，保持低饱和、同色相。

文字：**2处**手写体英文短句：
- 椭圆气泡框内：默认 `Pets save the world`
- 格纹便签纸上：默认 `little things matter`

用户可自定义文案。无文字请求时保留空气泡框和空便签纸。

## 提示与验收

身份源图与参考职责 → 暖米色纯色底 → 中下撕纸宠物 → 3条胶带分别贴左下方/右上方/右下方边缘 → 线圈涂鸦在左侧 → 星星分布在头顶/左下方/右下方 → 气泡框在右上角 → 小格纹便签在右下角 → 装饰紧凑围绕主体不分散 → 顶部大留白。

避免：冷白背景、爱心暗纹、粉色/绿色点缀、草莓、零散小爱心、短放射线、蕾丝、厚浮雕阴影、卡通化、装饰太分散到处都是、装饰围成圆圈/椭圆框、装饰对称排列。特别检查：装饰是否紧凑围绕主体、胶带是否紧贴边缘、便签是否够小且边缘不规则、装饰不分散成满天星。

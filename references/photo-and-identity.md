# 照片选择与身份

对每个 pet_id 记录实际可见的脸型、眼距与眼色、鼻/喙颜色、耳形、口鼻长度、毛发/羽毛纹理、关键斑纹、胸腹颜色、尾巴及已有衣服/项圈。不猜不可见部位，不以品种标准脸替代个体；默认不镜像有不对称斑纹的主体。

同一宠物在不同光线下允许毛色观感变化，耳朵可因姿态而直立或下垂。不能为了统一而把所有照片改成相同表情。多个相似宠物身份不清且影响必需出现数量时，问一次具体的对应问题。

非猫狗遵守其真实解剖：鸟保留喙、翅膀与爪形，兔保留长耳与真实口鼻，爬行动物保留鳞片和原肢体等。装饰性爪印可换抽象星点/爱心，不强加狗脚印、宠物服装，也不因主题可爱就变玩偶。

| 输入 | 处理 |
|---|---|
| 一张、一个宠物 | 一个主照片贴纸，保留完整可见姿态或裁成头胸 |
| 一张合照、多宠 | 优先保留合照关系；主体可分离时才拆开，不漏指定宠物 |
| 一张要三款 | 三款用同一真实照片，各自调整布局 |
| 一张明确要多次出现 | 可重复原照或使用整体与局部裁切，说明同图复用，不生成新姿态 |
| 同一宠物 2—3 张 | 清晰有表现力的一张为主，其余为辅；写清源图与槽位 |
| 同一宠物 4—6 张 | 用不同表情/姿态建立变化；未要求全用时可选最有信息的照片并记录 |
| 多只宠物 | 独立 pet_id；每只指定宠物出现。A/B/D 可用相邻双宠/合照贴纸组 |
| 明确所有照片都要 | 不静默丢图；过多无法保持识别时提出分成多张的具体方案 |
| 头像、遮挡、身体出画 | 头像、半身、相框或直线截断，不补腿、不补翅膀、不换姿态 |
| 模糊/过曝 | 可缩小贴纸；若身份不可辨，请求清晰原照，不凭空“修复”成新脸 |

未要求换装或加饰时，保留已有服装、项圈；不能把参考里的帽子、围兜、花纹搬来。背景蝴蝶结不自动戴在宠物身上。

去背景时不生成被人物/物品遮挡的身体，用较紧裁切或纸框遮边。照片剪贴可以保留直线下沿，不必每张都是完整全身。

常见偏差与处理：

- 大眼短嘴、头变大、毛发玩偶化：强调原口鼻长度、头身比例、摄影细节。
- 白毛融纸底：细灰外纸边或主题色轮廓分离，不把白毛染灰。
- 黑毛变一整块：保留原照可见暗部纹理与眼睛，不改毛色来突出主体。
- 去牵引绳连带改项圈/脚：重查原照，改用无需补身体的裁切。
- 用生成脸继续做其他款：各款重新引用用户原照，避免身份偏差累积。
